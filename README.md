# کیبورد آیفون برای اندروید ⌨️

کیبوردی برای گوشی‌های اندروید که ظاهر و رفتارش دقیقاً مثل **کیبورد iPhone** است، با پشتیبانی از **فارسی** و **English** و **صدای تایپ با بلندی قابل تنظیم**.

## ویژگی‌ها

**ظاهر iOS**
- رنگ‌ها، اندازه‌ها، گوشه‌های گرد و سایهٔ کلیدها مثل iOS (حالت روشن و تیره، یا خودکار بر اساس گوشی)
- بالن بزرگ‌شدن حرف هنگام لمس (Key preview)
- آیکن‌های iOS برای shift، حذف، 🌐 و ایموجی
- دکمهٔ return آبی برای «برو / جستجو / ارسال / تمام»، مثل iPhone

**زبان‌ها و صفحه‌ها**
- چیدمان فارسی iOS (ض ص ث ق ف غ ع ه خ ح ج چ …) + صفحهٔ shift با اعراب (ً ٌ ٍ َ ُ ِ ّ ْ)، ء، أ، ؤ، ئ، «» و …
- دکمهٔ **نیم‌فاصله**
- چیدمان QWERTY انگلیسی
- صفحهٔ اعداد و نمادها (123 و ‎#+=‎) — با اعداد فارسی ۱۲۳ در کیبورد فارسی (قابل خاموش کردن)
- صفحهٔ ایموجی با دسته‌بندی و «پرکاربردها»
- برای فیلدهای ایمیل دکمهٔ @ و . و برای آدرس اینترنتی دکمهٔ ‎.com‎

**رفتارهای iPhone**
- 🌐 تغییر زبان؛ نگه داشتن 🌐 = انتخاب کیبورد دیگر
- نگه داشتن حروف = حروف ویژه (é ñ ü … / آ أ إ ئ ۀ ة ك …)
- **نگه داشتن فاصله و کشیدن انگشت = جابه‌جایی مکان‌نما (ترک‌پد)**
- دو بار زدن ⇧ = Caps Lock، حرف بزرگ خودکار در شروع جمله
- دو بار زدن فاصله = «. »
- نگه داشتن حذف = پاک کردن پشت‌سرهم و بعد کلمه‌به‌کلمه
- لمس 123 و کشیدن انگشت روی یک عدد = تایپ عدد و برگشت خودکار به حروف
- نوار پیشنهاد کلمات (فارسی و انگلیسی) که کلمات شما را یاد می‌گیرد
- تایپ غلتان با چند انگشت

**صدا و لرزش**
- سه صدای جدا مثل iPhone: حروف، حذف، و کلیدهای ویژه
- **اسلایدر بلندی صدا ۰٪ تا ۱۰۰٪** با پیش‌نمایش زنده
- گزینهٔ بی‌صدا شدن در حالت سکوت گوشی
- لرزش با شدت قابل تنظیم
- تنظیم ارتفاع کیبورد

## نصب

1. فایل **iPhoneKeyboard.apk** را از بخش **Releases** همین مخزن (یا Actions ← Artifacts) دانلود کنید.
2. روی گوشی نصب کنید (اجازهٔ «نصب از منابع ناشناس» را بدهید).
3. برنامهٔ «کیبورد آیفون» را باز کنید:
   - **مرحلهٔ ۱:** فعال‌سازی کیبورد در تنظیمات
   - **مرحلهٔ ۲:** انتخاب «کیبورد آیفون» به عنوان کیبورد
4. از همان صفحه بلندی صدا، لرزش، تم و بقیهٔ تنظیمات را تغییر دهید.

> حداقل اندروید ۸ (API 26).

## ساخت از سورس

```bash
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```

با هر push، GitHub Actions به‌طور خودکار APK را می‌سازد.
کلید امضای `keystore/release.jks` فقط برای نصب شخصی و به‌روزرسانی بدون حذف برنامه در مخزن قرار گرفته است؛
اگر می‌خواهید برنامه را منتشر کنید، کلید اختصاصی خودتان را بسازید.

## ساختار کد

| فایل | کار |
|---|---|
| `KeyboardService.kt` | سرویس کیبورد (InputMethodService): تایپ، shift، پیشنهادها، زبان |
| `KeyboardView.kt` | رسم کیبورد به سبک iOS، بالن، حروف ویژه، ترک‌پد، نوار پیشنهاد |
| `Layouts.kt` | چیدمان‌های فارسی، انگلیسی، اعداد و نمادها |
| `Feedback.kt` | ساخت و پخش صدای کلیدها (با بلندی قابل تنظیم) و لرزش |
| `EmojiView.kt`, `EmojiData.kt` | صفحهٔ ایموجی |
| `Suggest.kt` | پیشنهاد کلمات و یادگیری |
| `SettingsActivity.kt` | صفحهٔ تنظیمات به سبک iOS |
